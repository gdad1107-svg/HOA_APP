HOA Portal Backlog

Every feature in the clickable mock-up (Homeowner, Admin and Guard views), broken into user stories with Gherkin acceptance criteria, then put in priority and dependency order. Stories marked Not in mock-up are gaps the real app needs that the mock-up skips.

Priority (MoSCoW)Must: the portal fails its main job without it. Should: high value, can follow a release later. Could: worth building once the core is in use.
ReleasesR1 lets homeowners pay dues and get a receipt. Each later release builds only on what came before it, so any release can be the last one without leaving something half-built.
Order inside a releaseThe rank number is build order: a story never comes before a story it depends on. Needs lists those stories. Unblocks lists the stories waiting on it.
SizeS is up to 1 day, M is 2–3 days and L is 4–6 days of build and test with Claude Code, roughly in line with docs/backend-plan.md. Sol Arch should confirm these sizes.
